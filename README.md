# Super Resume FREE

免费简历制作工具

## 功能介绍

**所见即所得的简历编辑器**

- 左栏编辑表单、右栏 A4 实时预览
- 模块化管理：个人总结、教育经历、实习经历、项目经历、社团经历、技能、荣誉奖项等，支持增删、排序、隐藏

**真实模板系统**

- 多套经典模板（顶部色条 / 居中 / 左置布局，竖线分隔联系方式），模板样式按目录隔离存放
- 左侧抽屉式模板选择器，缩略图为真实渲染的迷你简历（非静态图片），点击即切换、可连续对比
- 主题色、字体、字号、行距、页边距等版面参数自由调整

**多简历管理**

- 简历列表页：新建、复制、重命名、删除
- 回收站：误删可恢复、可彻底删除
- 每份简历独立模板与内容，随时切换

**数据安全与迁移（纯前端，无后端）**

- 所有数据保存在浏览器 localStorage，断网可用、打开即用
- 导入 / 导出 JSON：单份简历或整库备份，跨浏览器、跨电脑迁移
- GitHub Gist 云同步：用自己的 GitHub Token 将简历库备份到私有 Gist；上传以本地为准覆盖云端，下载以云端为准整体替换本地，轻松实现多设备同步

**零依赖交付**

- 构建产物为单个 185KB 的 `index.html`（JS/CSS 全部内联），双击即可离线使用，无需 Node/服务器
